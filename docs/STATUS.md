# 范围与进度

## 已包含

资源解码、数值目录、可选名称目录、独立共享库和 SDL2 查看器。合成输入覆盖像素转换、裁切、链接帧、格式错误与尺寸预算。输入状态和呈现四边形仅是明确边界内的基础模型。

## 没有包含

完整游戏体验、原版素材、战斗研究载荷、条件伤害模型、接纳/HP接线、原进程调试和受限分析路径。独立原创练习场是内部实验，不作为本项目成品。

完整倒地应用与资源接纳/扣血接线未完成，相关研究不在本公开版本中；不得将条件演示视为完整游戏。

## 验证边界

公开测试使用程序生成的简单像素与格式记录，不需要原游戏安装。Linux 构建和合成资源测试会以本导出的实际结果记录。macOS 的构建分支保留，但不将 Linux 测试冒称为 Mac 实机验收。

## 后续

优先维护此基础层的可构建性、边界检查和文档。扩展功能须保持公开范围明确，不能依赖缺失私有资料后仍宣称可运行。资源显示与真实游戏行为是不同的验收范围。
