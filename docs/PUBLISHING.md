# 发布清单与边界

该仓库只发布资源工具和基础模型的自有实现、合成测试与运行文档。系统库不捆绑；SDL2、zlib、Python和编译器各自的许可仍由其发行方提供。

不上传：

- 原版EXE/DLL/PVF/NPK/IMG、角色和地图图片、音视频或转储
- 原始反汇编、进程地址、调试记录、受限研究材料或其依赖接线
- 账号、凭据、令牌、私人链接、个人机器目录
- 本机二进制、虚拟环境、缓存和生成的演示输出
- 未融合的候选战斗模型或内部原创练习场

`.gitignore`不替代检查。后续发布时必须检查实际待提交文件，保持测试依赖自包含，不以空缺私有模块掩盖无法运行的功能。

项目尚未声明开源许可证；原游戏资产不因本仓库公开而获得任何使用或再分发授权。
