# 外部资源输入约定

仓库不附原游戏资产，也不提供下载链接或自动获取流程。构建与默认测试只用自建合成数据。

需要查看自己的资源时：

1. 在仓库外准备自己有权使用的 NPK 文件；不要提供账号、令牌或登录信息。
2. 使用 `native_viewer.py --samples <目录> --receipt <新文件>`。查看器按数值包、条目与帧选择，不写回输入。
3. 命令行解码可用 `build/npk_preview --inspect <文件>` 或 `--export <文件> <新目录>`。输出目录必须不存在。

当前解码子集是 NPK 包中的 IMG v2，支持已实现的 BGRA32、ARGB1555、ARGB4444、原始/zlib像素与链接帧。遇到其他版本、格式、循环引用、越界或预算超限时拒绝。不能据此推断所有客户端资源均兼容。

NPK/IMG 的标识符和固定目录格式是解析协议常量，不是账号凭据。名称读取器只返回规范化目录项；不把内部资源名当文件写入路径。

本机生成的示例、输出、原素材和构建产物都在忽略范围内。`.gitignore`只是辅助保护；发布前仍须核对实际待提交文件列表。
